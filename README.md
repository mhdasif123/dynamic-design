# Email Signatures for Desiree Canlas

Professional, minimal email signatures for Dynamics Design & Project Management.

## 🎨 Two Signature Styles

1. **Modern Style** - Logo inline with name, gradient accent line, serif title
2. **Clean Style** - Vertical gradient bar, P/E/W labels, ultra compact

## 📦 Files

- `index.html` - Preview and copy both signatures
- `signature-modern-for-email.html` - Modern style HTML
- `signature-clean-for-email.html` - Clean style HTML

## 🚀 Deploy to Vercel

### Option 1: Vercel CLI

```bash
# Install Vercel CLI
npm i -g vercel

# Deploy
vercel
```

### Option 2: Vercel Dashboard

1. Go to [vercel.com](https://vercel.com)
2. Click "Add New Project"
3. Import this Git repository or drag & drop the folder
4. Click "Deploy"

## 📋 How to Use

1. Visit your deployed site
2. Click "Copy Signature" on your preferred style
3. Paste into your email client's signature settings

### Gmail
Settings → See all settings → General → Signature → Insert HTML

### Outlook
File → Options → Mail → Signatures → Paste

### Apple Mail
Mail → Settings → Signatures → Paste
